How it was built

The problem in detail

Customer service spends a large part of the day answering the same messages: "Where is my order?", "When will it arrive?", "How do I pay?". Each one means looking up the order in the system and typing a reply on WhatsApp.

A simple bot can answer the routine questions instantly, any time, and pass anything unusual to a person.

Approach

  1. Find the order number. A pattern match picks up "TW-12345", "tw 12345" or a bare five-digit number anywhere in the message.
  2. Look it up and explain the status. Each status (received, picking, packed, out for delivery, delivered on time or late, on credit hold, cancelled) has its own reply template with the relevant dates.
  3. Answer common questions. Keyword rules cover delivery times, payments, statements, returns, opening hours, cancellations and hand-over to a person.
  4. Fall back politely. If nothing matches, the bot lists what it can do instead of guessing.

The bot is about 150 lines of plain JavaScript (bot.js), with no libraries and no data leaving the browser. It runs on 2,948 orders (192 KB); "today" is 30 Sep 2026. Other things to ask: "My item arrived damaged", "Opening hours", "cancel TW-78578", or order TW-78563, TW-78560, TW-78537 and TW-78260.

In a live setup the bot would confirm the customer's account number or registered mobile before showing any order details.

How it would work in your business

Tools

  • Website chat widget, or WhatsApp through the WhatsApp Business Platform and an approved provider
  • Power Automate or a small API connecting the bot to the order or accounting system
  • Optional: Microsoft Copilot Studio, depending on the client's licences
  • Power BI to track question types, response times and hand-overs

What you provide

  • Read access to order status data (an export, a database view or an API)
  • Approved answers for FAQs, delivery areas, payment and return policies
  • A WhatsApp Business account if WhatsApp is used
  • Who should receive hand-overs, and during which hours
  • Rules for verifying a customer before order details are shown

Indicative effort: about 2 to 3 weeks for a first version with order lookup and FAQs, depending on how orders can be read from the client's system. The scope and a fixed price are confirmed after the paid reporting diagnostic. Nothing on this page is a client result.
